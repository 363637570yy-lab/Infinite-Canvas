# Infinite-Canvas 浏览器验收

## 边界

- 只负责浏览器操作、页面断言和证据产出；不负责 Git 写操作、服务器部署、协议字段设计和最终判断。
- 纯 API、模型列表和日志核对**不属于**浏览器验收，不触发本 Skill。
- 未获得本轮授权不得点击任何触发付费生成的按钮。

## 浏览器选择

| 场景 | 载体 |
|---|---|
| 默认 | Codex 内置浏览器 |
| 需要访问服务器本机地址 / 内置浏览器不可用 / 截图接口超时 | 服务器 DrissionPage（`4.1.1.4` + Chrome） |
| 用户明确要求复用本机登录态 | 本机 Chrome，并说明原因 |

Codex Browser 访问生产页面执行真实页面操作属于生产真实 UI 验收。它与服务器 DrissionPage 的区别只是浏览器运行位置及能否访问服务器本机地址，**不是证据真伪或验收级别的差异**。

已知：内置浏览器截图接口曾超时（2026-07-28），此时改由服务器截图完成视觉检查，并在报告中说明载体切换原因。

## 验收目标

**本仓库是公开仓库，入口地址、IP、端口和域名不写入本文件。** 页面目标、URL、期望文本和禁止文本统一读取本地 `.codex-project/vps-maintenance/browser-targets.json`（已被 `.gitignore` 排除）；公网入口以全局 `SERVER_INFO.md` 档案为准。目标文件缺失时停止，不得凭记忆拼地址。

## 标准断言

- 页面标题与关键标记存在，无空白、重叠、裁切或横向溢出。
- 控制台无 warning / error。
- 无验证码、异常流量拦截或错误跳转。
- 改动涉及的具体控件、选项和弹窗按预期渲染（例如新协议应在 API 设置中出现对应 `value` 选项）。
- 截图与摘要落到证据目录，报告中给出路径。

## 付费生成

- 只有用户本轮明确给出生成矩阵、冻结模型 / 参数 / 次数上限后，才可点击矩阵内真实生成。
- 主代理负责费用边界、服务器监测和最终判断；本 Skill 只负责页面动作与页面证据。
- API、任务、日志证据只能关联并解释页面动作，**不能冒充 UI 点击**。
- 超出矩阵的重试、补偿、配置修改或数据修改需要新增授权。

## 报告

报告实际执行的页面动作、断言结果、证据路径、跳过项和残余风险。截图不得包含 API Key、Token、Cookie 或完整鉴权头。
